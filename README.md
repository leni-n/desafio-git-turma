# Desafio Git da Turma

Projeto utilizado nas atividades da Unidade Curricular de Versionamento e Colaboração.

## Objetivo

Este repositório será desenvolvido de forma colaborativa utilizando Git e GitHub.

## Regras

- Não alterar diretamente a branch `main`.
- Cada alteração deverá estar relacionada a uma Issue.
- Cada equipe deverá trabalhar em sua própria branch.
- As alterações deverão ser enviadas por Pull Request.
- Todo Pull Request deverá ser revisado por outra equipe antes do merge.
